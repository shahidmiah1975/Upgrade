# EZMenu WPF migration POC

This branch contains a POC WPF app skeleton and a small in-memory order service to serve as the starting point for porting the WinForms/VB EZMenu codebase to WPF/C#.

Projects created:
- EZMenu.Core (models)
- EZMenu.Services (in-memory service)
- EZMenu.UI.Wpf (WPF POC)
- EZMenu.Tests (placeholder)

Next steps:
- I will extract and classify the files from EZMenu.zip and commit a detailed CSV.
- Then I will port selected core POCOs from the archive and continue implementing the POS screen features.
